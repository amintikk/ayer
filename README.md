# Ayer · tu calle, ayer

**https://ayer.aminox.dev** — See how any place in Spain has changed from the air, from 1956 to today, with the historical aerial photographs of the Spanish National Geographic Institute (IGN). Mira cómo ha cambiado cualquier lugar de España desde el aire, de 1956 a hoy.

- Type an address (CartoCiudad geocoder) and the map flies there.
- A year slider cross-fades between surveys; only the surveys that actually cover the area on screen appear.
- Curtain mode to compare two periods side by side.
- Timelapse playback and export to MP4/WebM (WebCodecs, MediaRecorder fallback) or GIF, made in the browser, with the place, year, IGN credit and a small site mark printed on top.
- Shareable links with the view in the URL and a server-built preview image.
- A gallery of 18 places with static pages (Spanish and English) for search engines.

## Data

| Survey | Source | Layer |
|---|---|---|
| American Flight, series B (1956-57) | WMS `https://www.ign.es/wms/pnoa-historico` | `AMS_1956-1957` |
| Interministerial (1973-86), National (1981-86) | same | `Interministerial_1973-1986`, `Nacional_1981-1986` |
| OLISTAT (1997-98), SIGPAC (1997-2003) | same | `OLISTAT`, `SIGPAC` |
| Annual PNOA 2004-2024 | same | `PNOA2004` … `PNOA2024` |
| Latest mosaic ("today") | WMTS `https://www.ign.es/wmts/pnoa-ma` | `OI.OrthoimageCoverage` |
| Street names (optional overlay) | WMTS `https://www.ign.es/wmts/ign-base` | `IGNBaseOrto` |
| Address search | `https://www.cartociudad.es/geocoder/api/geocoder` | `candidates`, `find`, `reverseGeocode` |

All of it is © Instituto Geográfico Nacional de España, licensed **CC BY 4.0** (`<product> <date> CC-BY 4.0 scne.es`, see the [IGN licence conditions](https://www.ign.es/resources/licencia/Condiciones_licenciaUso_IGN.pdf)). The map prints the credit of every visible survey under the image, and exports carry it on every frame.

Coverage is uneven: 1956 covers the mainland and the Balearics (not the Canaries, Ceuta or Melilla); the seventies-eighties surveys and OLISTAT are partial; each PNOA year covers only part of the country. The IGN answers a white image where a survey has no photo, so the client probes a 32 px image of the area around the centre for every survey and keeps those that are not blank (`src/map/availability.ts`).

## How it works

- **Vite + TypeScript**, no framework. **MapLibre GL** with one raster source per survey, all added up front and hidden; the slider makes two layers visible and blends their opacity, while the next ones stay visible at opacity 0 so their tiles are already downloaded (`src/map/photos.ts`). Every tile goes through a `retry://` protocol that retries 5xx and timeouts (the 1956 layer sometimes answers 500).
- **Curtain**: a second map, clipped with `clip-path`, follows the first one's camera (`src/map/curtain.ts`).
- **Export** (`src/map/export.ts`): stitches the tiles covering the frame for every survey, draws hold + cross-fade frames on a canvas and encodes them with `VideoEncoder` into MP4 ([mp4-muxer](https://github.com/Vanilagy/mp4-muxer)) or WebM ([webm-muxer](https://github.com/Vanilagy/webm-muxer)); `MediaRecorder` in real time when WebCodecs is missing; GIF with [gifenc](https://github.com/mattdesl/gifenc).
- **Static pages** are generated by `scripts/pages.ts` (landing, map shell, gallery, places, legal; Spanish at `/`, English at `/en/`), with shared header/footer partials in `src/site/partials/`, hreflang, canonical, Open Graph and `sitemap.xml`.
- **Server** (`deploy/nginx.conf`): static files plus a caching proxy to the IGN under `/ign/` (allow-listed layers and sizes, rate limited, 4 GB cache, no visitor data forwarded) and `/og/view`, a 1200×630 preview of a shared view computed with njs (`deploy/og.js`).
- **Privacy**: no cookies unless the visitor accepts Google Analytics in the consent banner.

## Development

```sh
npm install
npm run dev        # http://localhost:5173, /ign/* proxied straight to the IGN (no cache)
npm test           # translations, URL state, tile maths, gallery data
npm run build      # pages + type check + bundle into dist/
```

Build-time assets, regenerated from the IGN services when needed:

```sh
node tools/coverage.ts --places     # surveys available at each gallery place -> src/data/coverage.json
node tools/coverage-maps.ts         # coverage maps of the landing -> public/coverage/
node tools/make-images.ts [slug]    # gallery images and Open Graph cards -> public/places/, public/og/
node tools/favicons.ts              # PNG/ICO icons from public/icon.svg
```

`./deploy.sh` builds and copies the site and the nginx config to the server folder (`AYER_DEPLOY_DIR`, default `~/docker/ayer`).
